这套分数怎么来的

  1. 硬约束过滤：闭馆日、轮椅不可达、低步行人群的陡坡点，直接出局，不参与打分。
  2. 九维加权打分：口碑、兴趣、人群、天气、无障碍、步行、排队、路上、门票，逐项算分后求和。
  3. 贪心插入：每轮取当前可进入点里分最高的，卡死「到达 → 排队 → 游览 → 闭馆」四个时刻。
  4. 窗口回填：排不进的点不硬塞；开门前要干等超过 30 分钟的直接跳过，避免时间空转。
  5. 分组再平衡：长辈组与亲子组各算一遍，撞点的让后来者改道，午餐同店汇合。

行程是怎么排出来的

  1. 理解需求：从一句话里取城市、人数、同行人群、兴趣、时段，以及「轮椅 / 腿脚不好 / 怕晒」这类约束。
  2. 过滤：闭馆日、轮椅不可达、步行强度超标的景点直接排除。
  3. 打分：评分 + 兴趣命中 + 天气倾向 − 步行强度惩罚 − 排队时间惩罚 − 路上耗时。
  4. 排时：按分数贪心插入，每一站都算「移动 + 排队 + 游览」，并卡死开放时间与闭馆时间；11:30–13:30 强制留出午餐。
  5. 分组：同时有长辈和孩子时拆两组，各排各的，午餐同店汇合；两组撞点了就让亲子组改走别的景点错峰。
  6. 记账：门票 × 人数 + 市内交通 + 餐费 + 住宿，逐项列清。
